# Agent Note: 原生插件窗格渲染

Status: implemented

[English](2026-09-07-native-plugin-pane-rendering.md) | 中文

## 问题

外部终端控制需要与 DSH 对话一致的导航、输入展示和响应式布局。将已有 Kitty pane 表示为 DSH Agent 或 Console，会赋予插件实际并不持有的 Session 或进程所有权。

## 决策

布局接受 `panel` actor，通过 root 作用域的 `workspace.panel` 槽位渲染内容。其标识选择插件视图，不是 Session 标识。窗格布局保存在设备本地，插件持有所选外部目标和草稿。

Keyed `workspace.panel.header` 槽位按 actor ID 选择条目，将插件标题和返回操作放入原生窗格顶栏。布局保留分屏及关闭控件，未注册对应顶栏时提供通用标题。Kitty 窗口选择页持有新建窗口和显示选项，通过共享视图 store 将设置提供给终端内容。

每个窗格在自身内容区域渲染紧凑输入区，使草稿和发送操作紧邻对应输出。共享画布输入区会让发送目标取决于输入区视觉位置之外的焦点。Kitty 在 root store 中按窗格 ID 保存草稿、暂存图片及发送状态，使切换焦点和分屏树重新挂载都能保留未完成的输入。每次发送捕获窗格及选择版本；延迟回执只更新对应选择，即使用户依次选择 A、B、再回到 A，也不会修改新的草稿。

Agent 窗格按 Session 共用一个 editor，因此只有聚焦窗格绑定根节点、keymap 和 decorators。非聚焦窗格显示可聚焦的草稿镜像；editor 清理只解绑自己仍持有的 DOM 根节点。每个挂载窗格持有独立的持久化镜像 lease，包括同一 Session 的重复视图。只有活动输入区接收文档拖放，局部拖放处理器在文档接收之前消费对应批次。紧凑输入区通过折叠次要控件保留输出空间，不移除提交或权限功能。

Kitty 占据这些槽位，复用对话样式、UI primitives 和附件展示。附件组件接收 owner props 与翻译器，不需要 Session hooks；Kitty 在自身窗格内处理拖放，并禁用组件的 document 监听器。关闭窗格卸载内容，但不关闭外部终端。

Kitty 共用侧栏顶部操作槽位及 Console 新建按钮样式。窗口创建是针对明确选中的 Kitty 实例执行的已认证排队操作，在所选目录启动默认 shell，且不抢占焦点。返回的窗口 ID 只在该实例内解析，因为不同 Kitty 实例可能复用 ID。创建失败不会自动重试。

外部会话浏览器占据 keyed `sidebar.page` 条目。布局统一持有暂存的页面 key 和移动端目标，使浏览器历史表达主列表、插件窗口列表和所选终端。Kitty 持有窗口目录，并按布局窗格 ID 保存每个选择、跟随状态和末尾 Enter 选项。发送选项属于各自窗格，避免一个终端中的勾选框改变另一个终端的提交行为；单独按键不使用文本提交选项。统一的发送操作在草稿为空时发送 Enter，使终端选择菜单无需打开按键面板即可确认。勾选框在电脑和手机上均显示文字标签，便于发现仅发送文本的功能。侧栏 owner props 传递布局持有的焦点 ID；将焦点复制到插件 store 会让选择操作出现两个相互竞争的目标。返回列表保留所选窗口和草稿。选择另一个窗口只清空目标窗格的草稿和图片，递增选择版本，并重新挂载屏幕读取器。新分屏继承最后聚焦的 Kitty 选择；在布局重新挂载时保留这些记录，使分屏树变化不会清空其他窗格的选择。

布局持久化包含 Agent Session ID 和活动窗格。首次就绪的 Session 目录建立选择基线，而不构成外部选择：若将恢复的全局当前 Session 当作用户操作，就会覆盖独立恢复的 Kitty、Console 或 Agent 窗格。后续侧栏选择仍替换聚焦窗格。移动端渲染保留完整窗格树，仅显示聚焦窗格。每个显式 Session 区域向嵌套槽位提供自己的绑定，并独立于全局选择订阅可用性、源名册重建和释放，因此延迟到达的目录无需改变焦点即可填充恢复的 Agent 窗格。

Kitty 仅在当前来源的浏览器本地存储中持久化每个窗格的非凭据标识 `windowId`，并从新目录中解析当前 token。该标识对主机启动 ID、socket 及 inode、数字窗口 ID、创建信息和根进程标识进行哈希；前台进程和展示字段不能标识持久窗口。Runtime 重启保留该标识，主机重启及窗口替换使其失效，即使没有创建时间戳也成立。按标题或数字 ID 匹配可能静默连接其他终端，持久化绑定进程的 token 则会保留过期授权。窗口缺失时必须显式选择；目录读取失败保留已保存标识以便重试。恢复从不发送输入，也不持久化 token、草稿、暂存图片或末尾 Enter 选项。

Kitty 的已认证目录通过首页 fetch preload 开始读取，使请求与插件加载重叠。Client 激活时消费预加载响应，并独立于视图挂载持有进行中的读取。打开选择页会共享进行中的读取，或先显示保留的列表并刷新；强制刷新取消前一次读取，只有最新响应能发布。卸载会中止并等待所有目录读取结束。HTTP 响应仍使用 `no-store`，空布局保持普通主页面导航，不选择终端。

浏览器滚动到边缘后，通过有上限的排队 `scroll-window` 操作滚动 Kitty 视口，再使用同一 pane token 读取屏幕。发送方向键会编辑输入或调用前台应用的命令。快照替换可能让原始触摸节点脱离文档，因此手势监听器保留在该节点直到手指抬起，使连续滑动不被屏幕刷新中断。目标或模式改变后，过时读取不能发布结果。

纯横向分隔线及纯 Braille 行使用 CSS 单行裁切，宽度限制为当前窗格。星点动画会在每次快照中改变文本长度和间距；对此类行折行会改变输出高度，使周围文字移位。ANSI 解析按完整可见行分类，同时保留跨行颜色与链接。CSS 裁切装饰行，无需随机采样或估计字体宽度；混有正文的行仍可折行。

窗格、分屏和预览标识使用共享的加密 UUID 辅助函数.直接调用 `crypto.randomUUID` 要求浏览器安全上下文，会导致这些视图无法在内网 HTTP 来源中打开；辅助函数使用在那里可用的 `crypto.getRandomValues`。

## 考虑过的替代方案

独立覆盖层重复原生导航和输入样式。复用 Agent 或 Console actor 会错误声明所有权。基于 [Host-owned Console Sessions](../../rejected/feature/2026-08-25-host-owned-console-sessions.zh.md) 中的原因，终端屏幕不解析为模型消息记录，而以快照展示。

**终端顶部下拉框**使手机端切换窗口依赖紧凑的表单控件，父列表也不进入浏览器历史。**替换工作区槽位注册**会移除它声明的子槽位。独立的 keyed 页面保留这些声明，由 shell 选择浏览内容。

**点击后才读取目录**会把发现窗口和一次网络往返放在完整插件启动之后。页面内预加载让这些成本重叠，无需持久化绑定进程的 pane token，也不改变全部插件激活的要求。

## 影响

插件视图共用原生窗格导航，不产生模型可见事件。此 profile 的单一渲染槽位只有一个占据者；增加视图提供方需要显式组合。布局恢复与挂载渲染检查覆盖 panel 标识，且不暂存 Session；附件检查覆盖禁用 document 拖放接收。
